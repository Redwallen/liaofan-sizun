# 《了凡四训》逐句精读

一个纯静态的互动学习网站，帮助不懂文言文的读者一句一句读懂《了凡四训》。
电脑、平板、手机都能用，并支持「添加到主屏幕」离线阅读。

**在线访问：** https://redwallen.github.io/liaofan-sizun/

---

## 快速开始

**在线**：直接打开上面的 GitHub Pages 地址，手机上用 Safari / Chrome 打开后「添加到主屏幕」，就是一个离线可用的读书 App。

**本地**：双击 `index.html` 即可（内容已内嵌，不依赖服务器）。想用本地服务：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 功能

### 阅读

- **逐句精读**：一次只显示一句原文，点「看白话」或直接点原文，才展开现代汉语翻译，读懂再进下一句。
- **通篇对照**：整节原文铺开，每句可单独点开白话，另有「全部展开 / 收起」便于复习。
- **字词注释**：人名、地名、官职、典故、冷僻字都会标红，点一下弹出解释，页面下方也有完整注释卡片。
- **心得**：每节配一段「这一节在说什么」，点出作者用意，而不是复述译文。
- **朗读**：调用浏览器内置中文语音朗读原文，可调语速。

### 学习管理

- **进度与笔记**：读到哪、哪些句子看过、自己写的笔记都存在本机，可「标记已掌握」，并汇总总进度。
- **全文搜索**：可搜原文、译文、注释与人名，例如「立命」「云谷」「谦虚」。
- **字词总表**：全书 968 条注释按词语排序，可按篇筛选。
- **我的笔记**：集中查看和跳回自己写过的每一段笔记。

### 手机适配

- **底部标签栏**：目录 / 字词 / 笔记 / 设置固定在屏幕底部，拇指可及，点击区域不小于 44px。
- **底部操作条**：逐句精读时，上一句 / 看白话 / 朗读 固定在屏幕底部，单手就能读完一节。
- **左右滑动**：左滑展开白话或进下一句，右滑回上一句；纵向滚动和在按钮上滑动不会误触发。
- **安全区域**：处理了 iPhone 刘海与底部横条的 `safe-area-inset`。
- **PWA**：带 manifest 与 Service Worker，可添加到主屏幕、离线阅读。

### 其他

- 纸白 / 米黄 / 夜读三种主题，四档字号，原文可切换**竖排**（自右向左）。
- 阅读进度用 `localStorage` 保存，纯前端，不上传任何数据。

## 目录结构

```
.
├── index.html              页面骨架
├── manifest.webmanifest    PWA 清单
├── sw.js                   Service Worker（离线缓存）
├── css/style.css           样式（含手机端适配）
├── js/app.js               应用逻辑（无依赖）
├── data/
│   ├── book.js             由构建脚本生成，页面实际加载这个
│   └── book.json           同样内容的 JSON，便于复用
├── content/                内容源文件（改内容改这里）
│   ├── _INSTRUCTIONS.md      编写规范
│   ├── _TEMPLATE.json        数据结构示例
│   ├── ch1.json              立命之学
│   ├── ch2.json              改过之法
│   ├── ch3a.json             积善之方（前半）
│   ├── ch3b.json             积善之方（后半）
│   └── ch4.json              谦德之效
├── source/                 从 EPUB 提取的原文，用于校对
├── icons/                  图标（由脚本生成）
└── tools/
    ├── build.py            合并 content/*.json → data/book.js，并校验原文
    └── make_icons.py       生成 PWA / apple-touch-icon / favicon
```

---

## 修改内容后重新构建

```bash
python3 tools/build.py      # 合并内容并校验原文是否完整
python3 tools/make_icons.py # 需要改图标时再跑
```

`build.py` 会：

1. 合并 `content/` 下的分章 JSON，按篇重新编号（`ch1-s01`、`ch2-s01`…）。
2. 逐篇比对「内容里的原文」与 `source/` 里的原书文本，报告是否有多字、漏字或错字。
3. 生成 `data/book.js` 与 `data/book.json`。

> 改了 `index.html` / `css` / `js` / `data` 之后，请把 `sw.js` 顶部的 `VERSION` 加一，否则已装到主屏幕的设备会继续用旧缓存。

## 数据结构

见 `content/_TEMPLATE.json`。一节（section）包含：

| 字段 | 说明 |
| --- | --- |
| `id` | 由构建脚本按篇重排，无需手写 |
| `title` | 这一节的小标题 |
| `pairs` | 逐句对照数组，每项 `{ orig, trans }` |
| `notes` | 注释数组，每项 `{ term, explain }`；`term` 会在原文中自动标红（支持带拼音写法，如 `夙（sù）心`） |
| `insight` | 这一节的心得 |
